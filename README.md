> Задание
> 
> В рамках выполнения второй лабораторной работы Вам необходимо создать лонгрид (long read) на основе материалов, подготовленных в лабораторной работе №1.
> 1. Создать необходимо мультимедиа лонгрид, который представляет собой материал, который сочетает в себе разные формы подачи информации: текст, фото, видео, графику, анимацию, аудио. Все элементы контента не просто дополняют друг друга, но и важны сами по себе, так как работают на раскрытие темы.
> 2. Минимально Ваш лонгрид должен состоять из заголовка, содержания (кликабельного), основного текста (содержащего не менее одного изображения на 5-7 тыс. слов), выводов.
> 3. В лонгрид необходимо добавить ссылки на: различные исследования по теме; экспертные статьи; практические кейсы.
> 4. Для создания можно использовать следующие среды и сервисы: Tilda, webflow.com и др.
> 5. В качестве ответа прикрепить ссылку на выполненную работу в соответствующий раздел ЭОС.
